# 原型与素材说明

本目录是供用户审核的静态视觉/交互设计稿，不是启动器产品实现。入口为 `review.html`，单页入口为 `index.html`。

用户截图中的游戏插画仅作为本次私有审稿参考；未取得独立分发许可，不作为正式启动器默认背景、发行包资产或宣传图。正式实现需替换为具备相应分发许可的插画，或使用用户本机自选背景。Starward 的代码许可不能推定为游戏插画许可。本目录没有复制 Starward 项目标识、游戏徽标或角色头像。

## 可复现预览

页面没有 CDN、外部字体、网络数据或服务请求，直接打开 `review.html` 即可；也可在本目录运行 `python -m http.server 18736 --bind 127.0.0.1` 后打开 `http://127.0.0.1:18736/review.html`。

单页参数：

| 参数 | 值 |
| --- | --- |
| `view` | `home`、`versions`、`engines`、`logs`、`settings` |
| `state` | `stopped`、`starting`、`running`、`stopping`、`error` |
| `setting` | `appearance`、`network`、`profiles`、`security`、`about` |

例如 `index.html?view=home&state=running`、`index.html?view=logs`、`index.html?view=settings&setting=about`。

默认对照尺寸为 1184×667；审稿页可切换 1024×640 和 1440×900。快捷键 1–5 切换页面，Tab 可遍历交互控件。`state` 可固定所有过渡状态便于截图；用户点击启动/停止会在本地用 1.5 秒/1 秒计时器模拟状态变化，不能据此声称实际性能已改善。

## 信息与功能口径

运行地址与示例日志用于演示，不连接该地址。环境页仅 Kohya 可用状态参考本轮已通过验收的事实；其余三引擎“未安装 · 示意”是画面占位，不是对当前机器的新检测。日志来源筛选、级别、搜索、复制、导出和跟随开关在原型内可操作；导出只包含本地虚构示例文本。

首页只有版本/更新/使用指引，没有游戏新闻或游玩时长。独立日志页是统一入口，各内容页不再常驻日志面板。设置页承接外观、网络、用户资料、安全与更新、关于，未恢复已删除的下载预算功能。

## 已覆盖与未覆盖的状态

本稿绘制首页停止、启动中、运行中、停止中、失败；启动中可取消本地模拟计时器，运行中可复制示例地址。尚未绘制首次空目录安装、checking（检查中）、degraded（服务失去健康）、stop_failed（停止失败）、有训练任务时的关闭确认，以及完整安装/修复进度页；这些属于后续设计和实现验收，不能从现有画面推导已完成。

环境页增加主程序环境分组、主程序精准修复和高级恢复入口；高级恢复弹窗明确包含基础 Python 恢复、主程序实例重建和登记恢复，当前仅示意入口。浅色主题明确禁用并标注待设计。背景模糊开关、遮罩滑杆和减少透明开关会实际改变本原型 CSS；这些预览不写入产品配置，也不跨重新加载持久保存。选择背景图片仍为入口示意，不启动文件选择或导入。

审稿页导航通过更新 iframe 的相对 URL 重载指定画面，兼容直接 `file:` 打开和本机 HTTP 服务，不依赖 `file:` 下的跨源消息。
