# 目标 2：Tag/自然语言 Caption 后端任务

## 目标

实现两条独立输出链路：WD/CL Tag 和具备 vision capability 的自然语言 Caption。任务具备 prompt snapshot、受限 data URL、严格 JSON、cache、atomic write、cancel、retry、report 和 conflict guard。

## 完成条件

- fake endpoint 完成 Tag 和 natural 两种输出；`output=combined` 被稳定拒绝，不新建 mixed；
- natural 输出按整段原文写回，不经过 Tag formatter；Tag 输出保持旧格式；
- 已有 caption 默认跳过，覆盖必须明确；单文件失败不拖垮批次；
- 文件外部修改触发 `caption_conflict`；取消保留已完成项；retry-failed 只处理失败项；
- 任务记录实际模型、运行方式、参数和 prompt 快照，公开报告不含 Key、路径、原始响应。

## 测试与证据

Unit：formatter、writer、hash、prompt、preset、cache key。Contract：jobs API/report/error schema。Integration：fake vision、local readiness、remote-first/fallback、恢复。Gray：旧 Tag 与新 Tag 逐文件比较。Real：本地 Qwen3-VL 低限额；远程已配置时记录 remote-first。

## 完成门

没有 Key/path/image payload 泄露；natural 不被 Tag 清理；所有失败有稳定错误码；job report 可恢复；首版不存在 combined/mixed 创建能力。
