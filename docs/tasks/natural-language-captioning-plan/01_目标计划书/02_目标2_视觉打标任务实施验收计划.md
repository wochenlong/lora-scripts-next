# 目标 2：视觉打标任务

## 目标

实现 natural/combined caption job，包含 prompt snapshot、data URL、JSON schema、cache、atomic write、cancel、retry、report 和 conflict guard。

## 完成条件

- fake endpoint 完成三种模式；
- natural 输出按原文写回，combined 使用明确 separator；
- ignore/copy/prepend/append 行为可测；
- 文件外部修改触发 caption_conflict；
- 取消保留已完成项，retry-failed 只处理失败项。

## 测试与证据

- Unit: formatter, writer, hash, prompt, cache key。
- Contract: jobs API and report schema。
- Integration: fake vision server and local endpoint。
- Real: 3-image remote and Qwen3-VL low-limit run。

## 完成门

没有 Key/path/image payload 泄露；所有失败都有稳定错误码；job report 可恢复。
