# 目标 5：隔离重建与从零真实验收

## 目标

在不复用开发工作树、旧依赖、旧配置、旧模型缓存和旧测试产物的前提下，从干净来源重新建立运行环境，证明 Issue #409 首版的后端、前端、Dataset Editor、统一 LLM 和本地模型路径可复现。

## 必要前提

- O1–O4 完成门通过，canonical task book、manifest、设计书和矩阵已冻结；
- 全新 worktree/干净源码、Python 3.11 venv、Node 22 依赖目录；
- 远程凭据只运行时注入，真实样本公开或脱敏；本地模型和资产来源、SHA、预算和清理策略已登记。

## 完成条件

- 依赖安装、后端启动、前端构建和健康检查从零通过；
- 空配置 Zero-Short 可操作；本地 Tag、自然语言 Caption、预览不写盘、取消、失败重试、冲突保护、原子写回和 Editor safety 通过；
- 有可用远程 Profile 时 remote-first/fallback 通过；没有凭据则记录未配置，不伪造通过；
- 完整 unit/contract/integration/gray/frontend/real/EDD/Zero-Short 矩阵有证据；
- 不执行或展示 combined/mixed 新建链路；
- 完成输入 hash、前后 hash、隐私扫描、清理和人工验收；无 Key、路径、图片、原始响应、模型二进制入 Git。

## 完成门

任何失败都必须记录并回到对应阶段修复，然后建立新的 fresh root 重跑；不能在失败环境上补丁式宣告完成。最终复盘必须明确写出隔离重建通过。
