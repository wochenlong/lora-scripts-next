# 目标 1：Issue #409 契约、统一 LLM 与模型能力

## 目标

让翻译与Tag/Caption共用Profile、资产、runtime、cache、revision和连接测试；翻译不要求vision，Caption模型目录必须声明vision/caption，共享Profile必须声明vision并支持图片请求；页面按本地模型/API服务和具体模型能力组织。逻辑supports_*能力在线上目录用capabilities数组和runtime表达，不新增重复布尔字段。

## 完成条件

- v4 translation config 可迁移到统一配置，profile revision 不含明文 Key；
- 模型注册表声明 supports_tag、supports_caption、supports_vision、transport、下载状态和专属参数；
- text-only profile 可用于翻译但不能用于 Caption；不适用参数前后端均拒绝；
- Caption 预设可迁移到 `user_data/presets/`，使用 `kind=caption_prompt` 并与训练预设隔离；
- 已配置远程 Profile 时 remote-first，local fallback 只有显式启用才允许；无 API 配置时没有空入口；
- 旧翻译 API 和 `/api/interrogate` 行为不变。

## 测试与证据

Unit/Contract/Gray：配置、mask、revision、capability、preset CRUD、错误码和旧 facade parity。Integration：fake text/vision。Real/Zero-Short：本地 readiness、空配置可操作状态；已配置远程时记录连接测试。

## 完成门

契约文档、schema、迁移 fixture 和回滚 fixture 一致；无 combined/mixed 新入口、无 Agent 依赖；P0/P1 安全和兼容测试通过。
