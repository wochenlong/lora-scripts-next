# 目标 3：Model-first 前端、user_data 预设与编辑器安全

## 目标

按 Issue #409 将 TaggerPage 改为数据集、运行方式、具体模型、专属参数/提示词、输出设置、底部进度的流程；按 capability 提供 Tag 或 Caption；Dataset Editor 保证自然语言文本安全。

## 完成条件

- 模型系列折叠/搜索/具体型号/下载状态正常；text-only 模型不出现在 Caption 选择中；
- 参数随模型隔离，请求不带不适用字段；没有 API Profile 时不显示空 API 入口；
- Caption prompt 预设使用 `user_data/presets/`，保存、另存为、恢复默认、未保存修改保护和跨浏览器读取通过；训练预设不加载 Caption 预设；
- 单图试标与批量使用同一配置，试标不写盘；批量底部显示进度，支持取消和失败重试；
- 不显示 combined/mixed 入口；Tag 操作不能清理 natural、unknown 或历史 mixed 原文；旧 Tag 表单回归。

## 测试与证据

Node 22 check、typecheck、lint、Vitest、build；组件测试覆盖 capability/model/preset/preview/progress/cancel；手测覆盖桌面、390px、Tab/Escape、空配置、错误、隐私提示和 Dataset Editor。

## 完成门

生产构建通过，核心交互有浏览器记录；模型切换和预设跨刷新行为可复现；无常驻右侧进度栏；前后端 contract 一致。
