# 目标 3：前端与编辑器安全

## 目标

在 TaggerPage 提供三种模式、profile 选择、提示词、预览、进度、重试和共享 LLM 设置；Dataset Editor 正确识别 tag/natural/mixed。

## 完成条件

- text-only profile 不出现在 caption 选择项；
- remote profile 排在本地 profile 前并显示外发提示；
- prompt cancel 不污染 committed config；
- mixed caption 不被 Tag 清理、排序和 underscore 转换破坏；
- 旧 Tag 表单和路由回归。

## 测试与证据

- Vue typecheck/lint/Vitest/build。
- 组件测试：mode, capability, progress, cancellation, i18n。
- 手测：桌面、窄屏、键盘、错误、空配置。

## 完成门

Node 22 的 npm run check 通过，生产构建通过，核心交互有手测记录。
