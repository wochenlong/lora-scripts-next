# 阶段 2：Tag/Caption 后端任务长程任务书

## 目标

建立 Tag 和自然语言 Caption 两条独立、持久、可取消且安全写回的任务链路。

## 任务

1. 保持旧 Tag API；Caption 使用 runtime/model/capability/output contract。
2. 实现受限 JPEG data URL、strict JSON、语言/长度/不臆测校验、prompt snapshot 和 cache。
3. 实现任务持久化、报告、取消、失败项重试、恢复、默认跳过和明确覆盖。
4. 分离 Tag/natural formatter；`output=combined` 稳定拒绝，不生成 mixed。
5. 保持 in-use、before hash、atomic write、rollback/clear、conflict guard。

## 完成门

Fake endpoint 覆盖成功、非法 JSON、超时、429、取消、部分失败、重试和恢复；natural 原文安全；旧 Tag 逐文件兼容；所有报告脱敏。
