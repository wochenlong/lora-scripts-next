## Purpose

在现有 TaggerPage 接入自然语言打标，同时保持 Tag 工作流和 Dataset Editor 数据安全。

## 执行步骤

1. 扩展 api/llm.ts、api/tagger.ts 类型和 jobs client。
2. 抽出 useLlmProfiles、useTaggerJob、prompt editor、progress components。
3. 在 TaggerPage 增加 Tag/natural/combined 模式。
4. profile 列表按 remote-first 排序，caption 只显示 vision profile。
5. 增加 preview、privacy hint、prompt preset、cancel/retry/report。
6. 抽取共享 LlmSettingsDialog，翻译和打标使用同一设置。
7. 后端 DatasetItem 增加 caption_format 与 mixed projections。
