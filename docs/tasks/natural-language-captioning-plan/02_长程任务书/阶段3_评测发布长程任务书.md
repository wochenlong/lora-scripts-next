# 阶段 3：评测、发布与维护

## Purpose

用真实和冻结证据决定默认 profile、文档、发布边界和长期维护方式。

## 执行步骤

1. 建立脱敏 caption eval set 和人工评分 rubric。
2. 对 SiliconFlow remote 和 Qwen3-VL local 运行 baseline。
3. 验证 prompt/profile revision 的缓存隔离。
4. 运行 real low-limit dataset、Zero-Short、privacy scan。
5. 复核失败样本、回滚、资源清理和 release notes。
6. 更新 canonical task book、manifest、design 和维护文档。

## 完成标准

- remote-first 中文路径和 local fallback 都有证据；
- P0/P1 问题为零或有明确授权；
- 评测报告、测试报告、回滚路径和资源清理记录齐全；
- 文档说明本地资源成本和远程外发边界。
