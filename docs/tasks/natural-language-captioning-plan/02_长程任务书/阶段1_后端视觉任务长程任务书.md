# 阶段 1：统一 LLM、模型和预设契约长程任务书

## 目标

让翻译、Tag 和 Caption 共用可验证的 Profile/asset/runtime/cache/secret 边界，并让模型 capability 决定参数和输出能力。

## 任务

1. 保持旧翻译配置迁移、旧翻译 API 和 `/api/interrogate` 兼容。
2. 补齐 supports_tag、supports_caption、supports_vision、transport、下载状态和参数 schema。
3. 将 Caption prompt preset 接入 `user_data/presets/`，以 `kind=caption_prompt` 与训练预设隔离。
4. 后端拒绝 text-only Caption 和不适用参数；无 API 时不展示空入口。
5. 保持 remote-first、显式 local fallback、密钥掩码和 revision/cache 隔离。
