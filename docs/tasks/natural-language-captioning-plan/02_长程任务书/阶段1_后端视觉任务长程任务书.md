# 阶段 1：后端视觉任务

## Purpose

建立可取消、可重试、可审计的 natural/combined caption job。

## 执行步骤

1. 实现 image resolver、RGB/JPEG resize、data URL 和 image hash。
2. 实现 prompt preset、snapshot、revision 和 JSON schema validation。
3. 实现 complete_vision adapter、timeouts、retry、stable error codes。
4. 实现 caption cache，key 包含 image/profile/prompt/preprocess revision。
5. 实现 Tag/natural/combined formatter 和 atomic writer。
6. 扩展 tagger job manager、progress、cancel、retry-failed、report。
7. 接入 dataset in-use lock 和 before hash conflict guard。
8. 用 fake server 覆盖成功、429、timeout、invalid JSON、cancel、partial failure。

## 完成标准

- 三种模式可由 fake integration 完成；
- remote-first fallback 有日志和报告；
- Key/path/image body 不进日志；
- 失败项可单独重试；
- Qwen3-VL-2B 低限额真实调用通过。

## Failure handling

单图失败继续任务并记录；文件冲突跳过且不覆盖；取消保留已完成项；所有任务失败则报告 error summary。
