## 锁定的最终完成口径

功能只有在以下集合全部通过时才算完成：

1. 后端：统一 LLM、远程优先/本地兜底、视觉能力校验、任务、提示词、缓存、取消、重试、报告和安全写回；
2. 前端：TaggerPage 三模式、共享设置、提示词编辑、预览、进度、取消、重试、错误/隐私提示和国际化；
3. Dataset Editor：tag/natural/mixed 识别、原文保留、危险 Tag 清理门禁、撤销/导出安全；
4. 兼容性：旧 Tag、旧翻译 API、旧配置迁移和旧 UI 回归；
5. 验证：unit、contract、integration、gray、frontend、real、EDD、Zero-Short 全部有实际证据；
6. 人工验收：桌面、窄屏、键盘、空配置、错误、隐私、取消、重试和回滚；
7. 隔离重建：新目录、新 Python 环境、新前端依赖、新配置、新测试输出，从零安装、构建、启动和真实验收；
8. 清理与安全：没有 Key、本地路径、用户图片、原始响应、模型二进制和缓存进入 Git 或证据。

## 隔离重建验收最小协议

隔离环境必须记录：

- 源 commit、工作树路径、操作系统、Node/Python/包管理器版本；
- 依赖安装和前后端构建命令；
- 空配置 Zero-Short 结果；
- 远程中文 profile 成功结果；
- 远程受控失败后显式本地 Qwen3-VL-2B 兜底结果；
- Tag、natural、combined 的输入 hash、输出摘要、写回前后 hash；
- 预览不写盘、取消、失败重试、外部修改冲突和 Dataset Editor mixed safety；
- 完整测试矩阵命令和结果；
- 隐私扫描、Git 状态扫描、临时资源清理和人工验收记录。

隔离重建禁止读取开发工作树中的旧配置、缓存、SQLite、模型、node_modules、.venv、未提交文件和测试输出；如果复用了某项资产，必须显式说明来源、SHA、授权和清理方式。
