# 总控目标索引

## 总目标

在 Dataset Tagger 页面建立安全可验证的 Tag / natural / combined 打标链路：统一管理翻译与视觉 LLM，远程 profile 永远优先，本地 profile 作为显式兜底；打标 profile 强制 vision capability，翻译 profile 不受此限制；原始 Tag 和自然语言 caption 均可安全写回并可被 Dataset Editor 识别。最终交付必须包含完整后端、前端、测试、人工验收，以及在隔离环境从零重建后的真实验收。

## 范围

- 统一 LLM 配置、profile、asset、runtime、cache、revision。
- 远程 OpenAI-compatible vision 与本地 Qwen3-VL-2B fallback。
- Tagger job、prompt、preview、progress、cancel、retry、report。
- TaggerPage、共享 LLM 设置和 Dataset Editor mixed safety。
- 完整测试和 EDD 评测。
- 隔离重建、从零安装/构建/启动、真实远程优先与本地兜底验收。

## 禁止突破的边界

- 不把 API Key 写进前端、Git、日志或报告。
- 不把本地路径发送到远程视觉 API。
- 不让 LLM 直接替代 WD/CL Tag 生成。
- 不让自然语言 caption 经过逗号 Tag 清理。
- 不允许 text-only profile 执行 vision job。
- 不删除用户已写回的 caption 作为回滚手段。

## 目标索引

| 目标 | 完成问题 | 解锁阶段 |
| --- | --- | --- |
| O1 统一 LLM | 翻译/打标是否共用配置且远程优先 | Phase 0 |
| O2 视觉任务 | 视觉请求、提示词、任务和安全写回是否完整 | Phase 1 |
| O3 用户界面 | TaggerPage 是否可配置、预览、执行和恢复 | Phase 2 |
| O4 评测交付 | 质量、回滚、Zero-Short 和发布证据是否闭环 | Phase 3 |
| O5 隔离重建验收 | 干净环境能否从零复现完整功能并通过真实验收 | Phase 4 |

## 完成口径

所有目标都有对应 unit、contract、integration、gray、real、Zero-Short、EDD 和人工验收或明确不适用说明；旧 Tag API 和翻译功能回归通过；远程中文路径和 Qwen3-VL-2B 本地路径均通过低限额真实验收；在全新目录和运行环境完成隔离重建；未授权 P0/P1 为零。

## 阶段解锁

Phase 1 需要 Phase 0 的 profile/revision/error contract；Phase 2 需要 Phase 1 的 job API 和 stable progress；Phase 3 需要前端和后端主路径通过 focused tests；Phase 4 需要 Phase 0–3 全部完成门通过，并且所有交付文档、构建产物和真实验收脚本已冻结。
