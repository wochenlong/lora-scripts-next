dev只在U0开工冻结一次；后续远端更新不是自动重开合并的理由。新版本解决不可回避问题时才记录变更并重验。最终证据必须绑定最终业务代码、依赖锁、模型/runtime；仅文档提交可用业务树hash证明无变化。旧历史报告只证明历史版本，不能补新门。
