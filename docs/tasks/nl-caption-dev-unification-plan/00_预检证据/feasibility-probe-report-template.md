# 可行性报告模板

- run_id / 时间 / 负责人：
- 代码commit / dirty hash / 工具链：
- 假设与对应风险 / 样本URL和hash：
- 模型、mmproj、runtime版本/URL/bytes/SHA：
- 硬件 / CPU线程 / context / 预处理 / 采样 / 非思考参数：
- 原始请求、脱敏响应、prompt hash、首次/重试次数：
- JSON/语言/长度、各维度评分与理由（自动/执行者/用户明确区分）：
- 冷启动/逐项耗时/p95/RSS峰值/取消时间线/共享PID：
- pass / fail / blocked / unrun，各硬门逐项结论：
- 失败解释 / 修复 / 重跑 / 候选选择及淘汰理由：
- 数据与资源保留/清理、下一步：

未测字段写unrun，不能填预期值充当观测值。
