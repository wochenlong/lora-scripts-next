# 测试、证据与资源治理

## 来源与状态

执行证据根：`docs/evidence/natural-language-captioning/dev-unification-20261010/U0/`至`U6/`。大型原始日志、进程资源采样和可复现模型留本次sandbox/tools专有目录；Git只保留脱敏的必要文本、报告、小型公开fixture/截图。

每次run记录run_id、时间/时区、commit与dirty差异、业务树hash、工具链绝对路径/版本、命令、退出码、模型/资产/runtime SHA、公开输入hash、实际provider、请求计数、输出摘要/证据路径。pass/fail/blocked/unrun/not-applicable分开。人工后续固定`pending_followup`；不得写为用户已评分。

## 真实调用限额与敏感信息

- 使用已获授权远程服务；运行时安全注入，不在命令参数/文件/证据复制Key。规划不主动真实调用。
- U4–U6累计最多120次远程请求（含重试），单请求输出不超过1024 tokens，样本最长边受既有预处理上限限制；并发1，最多2次退避重试。记录实际tokens及费用（若可得）。不购买服务、不创建付费资源；预算到达先优化去重，必要新增费用才请求决定。
- 本地探针预算见U1；后续真实验收最多150次本地请求，每次超时300秒。下载每文件最多3次完整尝试，坏hash/断网不无限重试。
- 所有测试仅用公开非敏感样本；远程只发去EXIF受限JPEG data URL。原始响应只在确认不含Key/路径等敏感信息后留证，禁止保存用户数据集图片。
- 全程同时磁盘占用预计不超过60GiB，至少留30GiB余量；执行前检查实际。耗时/容量超预算记原因，先处理本任务可再生中间产物，不能删除旧根。

## 保留与清理

必须保留失败报告、候选/资产锁、必要脱敏日志、输入输出hash、质量判定理由及最终证据索引。模型/依赖等可再下载大文件可清理；先写owned路径清单、解析绝对路径确认在本任务根、停止自有进程并检查端口，再用单一PowerShell的LiteralPath操作。删除拒绝不得换shell/工具绕过。

最终手测沙盒及其进程保留运行，不属于本轮清理目标。旧`nl-caption-manual-20261009`、用户resources、既有模型和无关dirty均保留。临时根不能清除时可登记明确保留与磁盘占用，不把自动审批拒绝伪装成功。关键证据缺失会阻挡关闭，是否物理删除所有可复现中间数据不是额外硬门。
