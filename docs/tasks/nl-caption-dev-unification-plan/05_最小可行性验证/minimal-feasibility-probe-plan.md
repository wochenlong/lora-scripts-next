## 固定输入与公平条件

1. 冻结6张公开非敏感样本：照片、静物/商品、插画、颜色数量、方位构图、少量可见文字；记录许可证/URL/SHA和可见事实参考，避免人脸敏感信息。相同data URL预处理，移除EXIF。
2. 每张用英文详细、英文简短、中文各一次，18个caption请求/候选；不择优丢弃失败输出。固定system/user全文、strict JSON结构、max_length和max_tokens。详细/简短的长度界限在首轮前写入fixture，后续不得为某候选单独放宽。
3. 12条英译中：完整训练描述和Tag短语、颜色/数量/方位/否定、专有词、标点/换行、可见文字；另加3条中文短路和混合文本误判测试。以可人工核对的事实/译法清单评价，不声称通用翻译基准。
4. 同机CPU模式、同线程数/上下文4096/图片尺寸/采样参数，顺序单模型运行，先空载基线后冷启动和热请求。Qwen3.5使用runtime支持的非思考选项，不依赖`/nothink`文本。记录实际chat template与运行参数。
5. 资源探针包含3次独立启动、长请求取消、text/vision交替与有界并发、服务重启，确认无第二份常驻模型。GPU若另测须独立标注。

## 最低门槛（执行前冻结）

| 指标 | AC-U1门槛 |
|---|---|
| 启动/协议 | 3/3启动成功；data URL实际识图；严格JSON、目标语言、长度最终18/18合法；每项最多1次受控生成重试且首次成功率≥17/18 |
| 内容质量 | 执行者逐条按主体/可见事实/目标语言/训练用途/精简度0–4评估，每维均分≥3；无任何0分或严重主体幻觉；完整保存理由 |
| 翻译质量 | 12/12非空合法中文，颜色/数值/方位/否定等关键事实无反转或丢失；准确/流畅/术语三维每维均分≥3；无整段照抄英文 |
| 中文短路 | 3/3不产生任何远程或本地推理请求；以调用计数证明 |
| 内存 | CPU进程树峰值RSS≤6GiB，记录进程树/整机内存；对照机32GiB不等于8GiB真机验证，默认建议16GiB以上 |
| 时间 | 排除网络下载，冷启动≤120秒；18条caption p95≤240秒；12条翻译p95≤90秒；披露实际数值与样本量 |
| 取消 | 用户收到取消确认≤2秒，停止生成/队列稳定≤10秒；若必须重启恢复≤60秒，无晚到写盘且下一任务成功 |
| 共享 | 同一资产/进程处理text和vision；并发串行化/有界排队，无OOM/串响应/互相误取消 |

评估由执行者完成，明确标注“自动校验+执行者内容评估”；不得称为用户人工评分。用户手验在U6交付之后，不要求在U1再向用户征集评分。结构/语言检查与质量评估分别记分，不能互相替代。

先比较两款2B：先淘汰不达硬门者；都达标时按视觉五维平均与翻译三维平均各50%形成质量分，差值≥0.2优先较高者；差值小于0.2优先资源更低者（先峰值RSS，接近10%以内再比较caption p95和下载大小）。执行者给出明确胜者及理由，不要求用户再选。0.8B若入选必须通过完全相同标准。若均失败，可修runtime/prompt通用问题或尝试相近小Qwen，但不得删样本、放松安全/事实门、将失败隐藏；形成新的候选记录。无法找到合格模型则AC-U1失败，不能交付空壳默认模型。

## 证据与预算

保存`locked-candidates.json`、`samples.json`、原始非敏感请求/脱敏响应、JSON与语言校验结果、资源采样、取消时间线、评分理由、`selection-decision.md`。引用commit、模型/mmproj/runtime SHA和prompt hash，输出到本轮evidence的`U1/`。

首批两模型约3.5GB模型下载；可选0.8B后约4.3GB，另计runtime。每候选含异常/重试最多80次推理；3候选最多240次。单请求硬超时300秒，探针总预算8小时；超出先报告耗时来源并优化/分批，不无限循环。预算不足不是通过理由。

从零阶段模型须重新下载。整个实施阶段磁盘同时占用计划上限60GiB、E盘至少留30GiB；不满足先清理本任务可复现中间产物或降低并发，不能删用户资源。远程真实验收预算见证据治理。

失败退回：协议/启动→runtime/manifest；语言/质量→候选或通用模板；内存/取消→运行参数与生命周期；修复重跑受影响项目，并完整保留之前失败。AC-U1未通过不得冻结默认资产。
