## 边界与冻结决策

- 仅涉及数据集 Tag/自然语言 Caption、翻译、共享 LLM、配置/预设/任务衔接、新 dev UI、相关测试与文档。Agent/sidecar/plugin/训练引擎不主动改造；dev 合并自然带入的代码单独核对来源。
- 远程 LLM 始终优先；本地是用户显式启用的兜底。无远程可用时可使用已启用的本地。Tag 词典保留；自然语言必须整句翻译，不能走 Tag 词典。
- 打标强制 vision；翻译只要求 text。默认英文，预设统一决定语言、详略、输出格式；无独立输出语言/详略下拉框。英文内置 user/system 提示词完整为英文。
- 自然语言只用原文编辑，译文只读；中文正文零模型调用。Tag 拆分、排序、拖拽、清理、批量 Tag 变更前后端均不得作用于 natural。保留草稿与文件 hash 冲突保护。
- 首版只有 Tag 或 Caption，不新增组合输出；不可用 API 不展示可执行空入口，可链接设置配置。
- 一套 `user_data/presets` 物理存储、完整 Caption 领域 schema、revision/事务保护、训练预设隔离；一个执行权威，任务页只是投影。
- Key 仅后端运行时注入，磁盘/日志/响应/证据只掩码或布尔。测试只使用公开非敏感样本。
- 保护 `tests/test_diffsynth_review.py` 的无关用户改动；保留原用户预设、配置、模型、数据集和旧沙盒。

## 执行与关闭顺序

严格按 U0 → U1 → U2 → U3 → U4 → U5 → U6 解锁。U2 后端契约冻结后可拆分无重叠工作并行准备 UI/测试，但不得提前签署后续完成门。模型下载与探测在 AC-U0 之后开始。

AC-U0 是可构建开发基线，允许记录后续 U2/U3 的已知适配缺口；不能有密钥泄露、数据破坏等无隔离的危险，也不能将占位功能算成完成。AC-U4/U5 才要求所有功能完成。
