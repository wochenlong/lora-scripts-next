# U1 双用途模型探测与默认选型

目标T2；依赖AC-U0。目的：用本轮可复查真实证据选择一个可承担翻译和视觉打标的小Qwen。

## 执行步骤

1. 在本任务独立探针根冻结样本、候选manifest和硬件/线程/上下文；读取[完整探针标准](../05_最小可行性验证/minimal-feasibility-probe-plan.md)。检查下载空间及运行时许可。
2. 下载并校验VL-2B对照与Qwen3.5-2B匹配GGUF/mmproj；探针可复用中间测试环境，但不能伪称从零验收。
3. 依次验证启动/健康/data URL/JSON，18个caption、12个翻译、中文短路，完整记录首次失败与有限重试。
4. 对同一进程进行文本/视觉交替、排队、取消与恢复，采样RSS/CPU/耗时；按公开样本逐项评估事实和训练用途。
5. 按硬门和选型排序自主决定默认；必要时加入0.8B或解决runtime兼容后同标准重测。候选选定前不把未证实capability写入正式就绪目录。
6. 产出默认模型锁、资源建议、质量理由和已淘汰候选原因。默认一个；旧模型保留可识别。

## 输出、验证与完成门 AC-U1

输出`locked-candidates.json`、样本hash、请求/响应、评分/资源报告、取消时间线、`selection-decision.md`。证据目录`docs/evidence/natural-language-captioning/dev-unification-20261010/U1/`。

探针表所有最低门槛通过；一套资产真实支持text+vision；选择有明确理由，下载URL/revision/SHA/mmproj/runtime完全锁定。质量评估标明执行者，用户人工验收仍pending_followup；历史评分不可复用。

## 失败退回

依次定位文件配套、runtime、通用模板、候选质量和资源；不放宽JSON/语言/文件安全来迁就模型。无人选达标则AC-U1失败，继续可独立完成的分析但不得宣布统一模型完成。完成后更新canonical并进入U2。
