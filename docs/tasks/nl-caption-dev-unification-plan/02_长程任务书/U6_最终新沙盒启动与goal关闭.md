# U6 最终新沙盒启动与goal关闭

目标T7；依赖AC-U5。目的：在所有验收通过之后，为用户另交付干净可操作的手测项目。

## 执行步骤

1. 固定最终业务源码等同U5 candidate；若只增加验收文档，可形成文档提交，但须证明业务树hash不变并记录两SHA。任何业务差异返回U4/U5。
2. 另建新`workspace/sandboxes/nl-caption-manual-<时间>-<run>/`，不覆盖`nl-caption-manual-20261009`和其它根；使用独立源码工作目录、配置/数据库/样本/日志。准备少量公开Tag与Caption样本、未打标副本、中文短路样本及可试冲突副本。
3. 安装并配置同一默认模型。资产可由U5成功根物理复制且校验hash，必须记录来源、无共享可写状态/硬链接；这是交付准备，不声称再次全新网络下载。Key不放启动脚本、不做命令行参数，运行时注入方式可复用安全服务入口。
4. 创建本根`start.ps1`/`stop.ps1`/手测说明，用隐藏窗口启动必要后台进程，PID文件绑定进程路径/启动时间，停止只操作本根进程。端口动态选择并固定到本根说明，不能占用或重启旧沙盒。
5. 验证PID+listener+HTTP健康+浏览器入口；选定模型text/vision就绪，做一次非敏感最小真实操作后保留干净手测副本。服务留运行，不在清理时停掉最终沙盒。
6. 审查AC-U0…AC-U6、范围diff、用户修改hash、证据与资源清单；canonical更新到自动验收及沙盒交付完成、manual=pending_followup，再关闭goal。

## 输出、验证与完成门 AC-U6

输出最终沙盒绝对路径、URL、应用/模型PID与健康、源码与资产版本、启动/停止方式、重启Key注入说明、重点手测单、已知限制与最终验收报告。证据`docs/evidence/natural-language-captioning/dev-unification-20261010/U6/`。

所有AC门pass，范围内P0/P1为零，必要测试无未核销失败/skip；feature名称与冻结祖先正确；用户dirty保留；最终新沙盒正在运行且可用。用户已明确“沙盒交付就绪后关闭，人工验收作为后续”，因此manual仍pending_followup可关闭，不需再次征求评分或关闭授权。

重点手测：新版布局/侧栏；预设切换与完整英文打标；单图不写盘与批量写盘；原文可见/保存/冲突；整句译文/中文免调用；自然语言Tag操作禁用；全局设置与一键模型共享；remote-first和显式fallback；任务取消/重试/历史；旧WD/CL兼容。

## 失败退回

启动/路径问题在交付根修复并重验；业务问题返回U4/U5；缺Key影响最终remote状态如实记录安全注入需求，但不能抹除本轮已完成真实remote证据。当前应用/本地模型未ready或沙盒不可打开则不能关闭goal。goal工具不可用时在canonical记录完成并说明工具限制，不伪称工具已关闭。
