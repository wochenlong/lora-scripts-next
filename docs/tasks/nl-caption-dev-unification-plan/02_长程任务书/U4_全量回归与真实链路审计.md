1. 全仓测试发现/收集，生成纳入、范围外、平台差异表；更新`tools/run_caption_scope_tests.py`覆盖新dev的user_data/API设置/proxy/路径/任务/配置/导入导出，审计没有遗漏共享修改的消费者。范围外测试不得偷偷执行真实外部API。

3. 真实远程（运行时Key）与选定本地模型分别走Caption/翻译；覆盖单图、批量、数据集磁盘、编辑可见、真实英译中、中文零调用、实际provider证明。限额内失败修复重跑，不能mock核销缺Key。

6. 桌面和390px浏览器重走关键旅程；检查日志/配置/导出/证据无Key、图片路径和EXIF泄露。审计diff没有Agent主动改造、没有降级JSON/hash/密钥保护。
7. 修复后按影响重跑；形成无未核销P0/P1的候选本地commit、业务树hash与资产锁，准备U5。
