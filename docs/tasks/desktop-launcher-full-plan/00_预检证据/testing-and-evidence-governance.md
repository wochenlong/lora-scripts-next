## 2. 六类测试与结论词

| 类型 | 本计划要求 | 不能替代的证据 |
| --- | --- | --- |
| unit（单元） | 操作状态、路径、配方、哈希、签名、空间计量等局部规则 | 不能证明安装或训练 |
| contract（合同） | Rust/Python网络向量、worker协议、能力声明、receipt/registry/操作版本兼容 | 不能证明真实入口可运行 |
| integration（集成） | 实际文件/子进程/解释器/HTTP/更新helper及故障注入 | 不能冒充干净系统 |
| gray（新旧对照） | 旧CLI/网页与受管桌面路径、旧receipt、迁移前后和失败回退差异 | 不能仅比较两个状态JSON |
| real（真实资源） | 实际下载、原生按钮、真实子进程、实际API与四引擎短训练 | 不能用mock或GUI 200替代引擎训练 |
| Zero-Short（干净入口短验） | M0–M5按阶段验证新根；M6必须真实干净Windows OS/VM且独立GPU重装 | 限制PATH、清空目录只算辅助 |

单项状态用 `pass/fail/not-run/blocked/unknown/not-applicable`。`not-applicable` 必须列出不适用原因、审批依据及替代证据；`unknown/not-run/skip` 不得计入完成数。M6 A1–A10的必测单元不允许用这些状态换取完成。阶段执行状态仍由总控的 `pending/in progress/blocked/done` 维护。

## 3. 待审真实资源硬预算

当前只读快照为 RTX 4060 Ti、16380MiB显存、驱动591.86；E盘约92GiB可用，F盘约997GiB可用。快照只证明当时资源，不证明模型能装入16G显存；开工重新采集。

| 项目 | 待审总限额 | 计量与停止条件 |
| --- | --- | --- |
| 新增网络 | 全计划累计≤200GiB | 下载、失败重试、断点重拉、依赖/模型/安装器都计入；不能把缓存命中估算当网卡计量 |
| F重型根 | 同时峰值≤300GiB，且卷剩余≥100GiB | 缓存、解压、环境、快照、模型、训练输出、OS镜像/虚拟磁盘均记账；每次重操作前复核 |
| E元证据 | 新增≤5GiB，且卷剩余≥20GiB | 保留关键原始日志/失败现场元数据；大权重与磁盘镜像留F并登记摘要 |
| GPU | 合计≤180分钟，同一时刻1个任务 | 包括可行性探针、失败和重试；统一GPU lease（租约）串行 |
| 单次短训练 | 最多20 optimizer steps或10分钟，先到即止 | 必须产出可校验权重；预先配置预算内保存间隔，不能伪造步数或用空文件代替 |
| 单引擎真实短训练失败重试 | 全计划同一引擎最多2次失败后重试 | 只计真实短训练失败后的重试；故意故障注入/中断恢复不计此次数，但其网络/GPU/磁盘照常入总账；M2/M3与M6的首次验收不是失败重试，不按阶段重置计数 |

建议阶段网络分配为 M0≤10、M1≤10、M2≤60、M3≤50、M4≤5、M5≤5、M6≤60GiB；GPU分配为 M0≤10、M2≤40、M3≤40、M6≤90分钟，总和分别200GiB与180分钟。阶段分配只是总预算内的计划，不承诺资源必定足够；调剂必须先更新资源账本和总控，不能突破总限额。单项和总项限额同时适用，不能因允许两次重试就超过阶段/总GPU时长。

M0先解析四引擎冻结配方、合法模型/数据、干净OS介质和WebView2资产的清单及容量。清单预计超限、16G不满足必要模型、缺VM/OS资源或权利不明时，停止相关真实任务并出具阻塞证据，不能偷偷换弱模型、降低验收或借远端服务器。付费云/服务器、真实生产签名、发布、真实资料读写不在本预算授权内。

M6 A4/A8必须由**同一最终交付包和同一二进制SHA**实际完成签名及helper恢复矩阵。可审的只读受限测试配置仅在显式启用且有根标记的新沙盒中生效，配置字节/摘要/启用参数入证据，不改变包字节或默认生产信任根。测试根/源只能作用本次沙盒，配方动作仍为内置白名单ID、资产仍验签验哈希；不得利用任意URL/命令执行绕过信任合同。拒绝对真实/既有非测试安装根启用测试配置，沙盒receipt/状态带测试来源，不得提升为生产信任。普通默认模式另实测拒绝测试签名、测试receipt与未授权覆盖配置。

## 5. 真实验收最低证据

原生UI保存可见操作、关键截图和动作结果；服务保存进程归属、端口监听及语义API/HTML/JS/CSS响应。引擎分开报告结构完整、导入、GPU小张量和短训练；训练权重使用对应格式读取器实际打开、检查非空张量及预期键、shape/dtype、有限值，并保存哈希。仅退出码0、生成文件名或GUI启动不算训练通过。

精准修复需记录固定计划身份、依赖闭包、允许改变/保留的路径，比较非目标组件和synthetic profile（合成资料）的前后字节/树摘要及关联身份；合法运行日志、操作记录等允许变化单列。无GPU、状态丢失、探测超时分别解释，不能自动推断需要重装。只读检查前后比较持久路径，证明没有隐式修venv或写autosave。

网络故障使用可控本地HTTP夹具与明确的真实下载组合，记录200/206/416、ETag/Content-Range及partial摘要；不得泄露代理密码。主机断网/限速只能作用于隔离任务，不能改系统全局代理或阻断他人服务。
