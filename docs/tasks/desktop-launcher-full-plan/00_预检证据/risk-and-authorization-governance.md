## 2. 预算提案和明确排除

全计划新增网络≤200GiB（含失败/重试），F重型根同时峰值≤300GiB且卷剩余≥100GiB，E新增元证据≤5GiB且卷剩余≥20GiB；GPU总计≤180分钟、同时1个任务、每次最多20 optimizer steps或10分钟先到即止，同引擎真实短训练失败重试全计划最多2次。故意故障注入/中断恢复不计该次数，其资源仍入总账。完整计量规则见[测试与证据治理](testing-and-evidence-governance.md)。

拟重型根 `F:/NextTrainerLauncherSandbox/<run-id>`，元证据根 `E:/OpenSourceTeamWork/workspace/tools/launcher-full-20261028/<run-id>`。根外代码只按规格限定源码改动；根外真实资料、系统环境、其他服务和凭据不因“全程执行”而授权。

以下操作须另行取得明确授权：新增付费云/收费API、购买或下载需额外许可的资产、借远端服务器、创建/使用生产签名密钥、向正式发布渠道上传、GitHub issue/PR评论等外发消息、读写/导入真实用户资料、原位接管真实旧安装、修改系统PATH/全局代理/驱动、超预算、删除根外数据。可以先完成不依赖它们的实现和本地夹具，整理具体资源/动作/影响供审核。

## 3. 风险分级与处置

| 级别 | 判断 | 处理 |
| --- | --- | --- |
| P0 | 资料破坏、路径越界、信任绕过、错误指针、误杀外部进程或无法回滚 | 停有风险的具体写入并保留现场，自主修复；独立施工继续，不冒称该路径通过 |
| P1 | 主要链路/合同缺陷、资源或预算不足 | 代码问题自主修复；资源只约束对应动作，系统实测集中 M6；硬预算或无法隔离真实风险才中断 |
| P2 | 已有安全替代但体验/次要行为欠缺 | 跟踪责任与补测；不得隐藏为pass |
| P3 | 文案、低风险文档和非必要改善 | 可按优先级处理，记录边界 |

## 5. 触发暂停与升级

任何路径解析越界、非目标资料哈希改变、外部进程异常、签名/哈希不符、资源账本失真、预算不足、来源许可未知立即停止该动作。先生成[failure report](failure-report-template.md)，保存原始输出和现场摘要，再按变更治理更新总控、任务书、goal与manifest；不无痕改变目标。

“暂停相关真实任务”不阻止可独立的文档、静态审查或受控本地修复。需要用户决定时，给出具体可审核的资源/预算差额或失败范围；不要要求用户重新批准已经明确授权且仍在范围内的动作。
