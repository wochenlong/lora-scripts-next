## 已实现内容与设计决策

1. Starward 远端与本地源码均为 `df8ae07b5ad4c9c6cb70d288488ce8073ce01478`，并用 WinUI 1.8.11 同代源码核对材质和控件。详见同目录源码调研。
2. 图片以整个窗口为坐标居中覆盖；仅保留源码的右边与右角渐变。首页只在 56px 导航处显示亚克力，其余页面显示全窗单一亚克力层，导航本身透明，避免侧边拼出另一块实体板。
3. 亚克力采用 SVG backdrop 滤镜，按顺序高斯模糊（默认30px、边缘duplicate）、luminosity亮度混合、color着色混合、2%细灰噪点。默认着色强度60对应有效luminosity约0.51925、tint约0.36078；普通黑色遮罩只作为滤镜不可用时的降级。实测排除了 CSS 子层 mix-blend 在 backdrop 中重复变暗的错误路径。
4. 正文14px、说明和日志元信息最小12px，Windows系统字体；默认按钮约6%白填充/8%悬停、细边框，主按钮44px高/22px圆角。单独调整输入、滑块、复选框、开关、选中行与内容容器。
5. 十处正式下拉统一为亚克力组合框；弹层Teleport、自动上下定位、选中短线、250/167ms进出，保持原数字或字符串模型、键盘及关闭行为。页面轻量220ms进入，背景300ms交接，全部服从减少动态。
6. 主题设置及旧主题字段已删除；旧默认28%/24px迁移为统一材质60%/30px，自定义背景、非默认强度、字号、减少动态继续保留。由于项目海报的左上区域明亮，首页品牌/版本/窗口操作文字按局部亮度自动使用深浅文字，不添加全屏遮罩。
