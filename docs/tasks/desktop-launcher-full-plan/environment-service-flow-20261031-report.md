# 环境管理运行态无法继续：功能返修

- 日期：2026-10-31（Asia/Shanghai）。状态：源码修正及浏览器定向回归完成，待打包交付。
- 触发：用户从零安装主程序后，网页安装引擎提示“桌面受管环境请使用启动器安装/精准修复接口”，桌面环境页的检查/管理按钮又全部禁用。
- 基线：`launcher-ui-baseline-20261031`仍固定在`7aa9d6c5`；当前开发分支`feat/desktop-launcher`。本次修正功能操作流程，不重新设计已冻结的美术。

## 已核事实与原因

网页旧安装器在`mikazuki/launcher/bindings.py`拒绝改动桌面正式环境，是原有受管保护。Rust运行训练器时持有工作区互斥，`engine_bridge.rs`的查询也取得同一互斥；`core.rs`进一步阻止运行态的引擎操作。因此仅将前端检查按钮解禁仍然不能成功，也不能让旧安装器绕过正式实例管理。

前端`mutationDisabled`把运行态传给整个EnginePanel，连只展开本地面板的“管理”也被禁用；环境页没有说明“先停止服务”，停止入口只在首页，造成用户无从继续。这是本次需要关闭的操作可达性问题。
