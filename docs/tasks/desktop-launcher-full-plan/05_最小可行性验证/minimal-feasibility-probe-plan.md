## 4. 真实命令记录合同

探针实现后记录精确脚本commit/hash、参数、工作目录、受管根、解释器路径、stdout/stderr/退出码和原始时间。只读系统采集输出先脱敏机器/用户名；不得导出凭据、历史或真实用户文件。模型/数据清单必须提供来源、许可、SHA256、架构/精度和预计显存；没有这些不开始GPU下载/训练。
