## 验收标准

| 编号 | 可验收结果 | 失败条件 |
| --- | --- | --- |
| M3-A1 | AI Toolkit/DiffSynth 各有发布兼容合同、独立解释器、固定上游/补丁、依赖锁与完整资产哈希 | 复用 GUI Python、临时注入源码或配方无法获取 |
| M3-A2 | 四引擎分别调用检查/诊断与修复入口，以合成/小夹具验证独立状态、RepairPlan及必要成功/拒绝/恢复分支 | 缺独立入口/计划、跨路径污染、dirty/generation/lease或失败拒写失效；把冒烟写成真实验证 |
| M3-A3 | 新引擎只读检查不改持久数据，定点修复受 dirty/generation、快照、锁和失败恢复保护 | 默认 force install、污染 GUI/其他引擎、取消后假健康 |
| M3-A4 | 接受清单前验证签名、规范编码、序号、有效期、平台、最低壳版本和资料合同 | 无签名远端动作、重放、错误 key/平台仍安装 |
| M3-A5 | receipt 保留原始签名封套、payload、信任链、时间/序号证据；schema 1 兼容读，未知格式拒写 | 仅保存 verified 标志、旧安装因远端下架丢身份 |
| M3-A6 | 过期/下架/安全撤销分别处理；保留旧公钥证明，可信撤销阻止自动及显式安装/激活/回退且不删资料 | 联网失败被猜成撤销、主动旧版选择或回退绕过已知撤销 |
| M3-A7 | 更新发现不阻塞健康启动；新版本验证后由用户显式选择，失败不改绑定 | 后台静默切 current、发布日期冒用 commit 时间 |

同包前置：实现同一交付二进制可审的显式沙盒会话配置，后端校验新隔离根、固定测试源/公钥和动作白名单，仅配置本身只读；普通根默认拒测试资产，UI不传任意URL/密钥/命令。另SHA测试构建只补协议证据，不抵M6最终包A4/A8；无此通路且无生产资源时必要格blocked。
源码身份门：候选训练器须从已推送 feature 完整 commit 生成源码及已编译前端归档，含实际 worker/引擎/路径改动，固定资产哈希与 recipe；测试 catalog 明示候选身份，不能冒充经验证 main，不能用原固定 main/dev 加开发 repo overlay 验收。
