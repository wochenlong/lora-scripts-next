## 验收标准

1. GUI 配方先锁平台、Python/ABI、依赖、上游/补丁和资产 SHA；不可锁资产明确限制，不能靠可变版本字符串宣称可复现。
2. operation 有独立 ID、阶段/结果、递增事件和检查点；取消句柄不等待长 Engine Mutex，跨进程 workspace lease 保证互斥。
3. 续传只追加合法 `206/Content-Range`；`200` 重下，验证器变化/`416` 核对后处理，镜像复用条件严格，最终完整 SHA256 必过。
4. 下载/ZIP 以实际字节、条目和压缩比计量；路径穿越、链接、重名和超限被拒，错误不能覆盖健康版本。
5. RepairPlan 只修目标依赖闭包；修改前独立 snapshot、实例 generation 递增及 dirty 落盘，取消不恢复旧健康标记。
6. 失败恢复同一绝对路径并重验；Windows venv 在最终固定实例路径创建，靠绑定原子激活；commit intent 含旧绑定/generation、候选摘要和回滚材料。
7. 基础 Python 修复停用整个引用闭包，受影响环境分别复验；操作失败仍保护资料、非目标组件及旧健康绑定。
8. 原生按钮实测取消/关窗、断网、强杀、磁盘不足及重启恢复，覆盖包文件已改变但尚未提交的故障窗口。
