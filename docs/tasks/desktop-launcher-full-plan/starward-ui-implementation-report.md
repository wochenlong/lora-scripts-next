## 已确认的实施边界

- 启动前必要可信源码、解释器、环境、绑定、租约、Job 和健康验证继续保留；runtime 查询不能全量扫环境或等待 Engine 长锁。
- 正式品牌资源从仓库复制并打包，禁止依赖 `127.0.0.1:2011`。正式背景使用项目已有角色与自制图形；Starward 游戏截图仅保留在设计采集材料中。
- 原 u13 普通启动器及其服务仍在运行，保持其进程和资料。实测使用当前没有服务归属的既有 r12 完整安装、全新启动器包与独立 WebView，避免重复下载和训练。
- 本轮验证是新版壳的界面与启停响应验证；不重新声称冷安装、四引擎训练、干净 Windows 或缺失 WebView2 首装通过。此前用户接受的测试边界继续保留。
- 构建输入清单新增 `public` 和 HTML/Vite/TS 配置，保证打包品牌及背景也参与冻结摘要。
