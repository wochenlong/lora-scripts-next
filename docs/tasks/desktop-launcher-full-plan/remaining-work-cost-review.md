# 候选之后的剩余工作与成本审核

本表按 CR-003 保留后续完整需求，供用户决定下一批范围。所有暂缓项均为 `deferred by CR-003, review after M1-CANDIDATE`；不因此计 pass、skip 或 done。估时是以当前代码/草稿和已知资源为依据的工程工作量区间，未获资源等待时间另计；新增构建/真实案例数是规划范围，失败重跑可能增加，需在下一批任务中封顶。

一个工程日按约 6–8 小时有效实现/审查/验证工作理解，属于工作量估计；不等于连续运行 AI 所需的日历时间，也不包含用户审核、缺失机器/许可和网络等待。

当前没有能可靠分摊本次工作、各协作者及历史运行的实际计费 token 明细，也没有本会话适用单价；token 用量与货币费用均为 **unknown**。Goal 工具的累计字段不等于供应商计费账单，不据此伪报精确金额。若后续提供实际账单/定价，才可据真实使用量估算。
