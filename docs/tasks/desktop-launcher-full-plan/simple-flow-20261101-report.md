- 版本管理负责下载安装、切换、回退、删除；技术身份和源码维护入口移入详情/环境高级。
- 环境每项提供一个状态驱动主按钮：未安装为安装，已安装为检查并修复，中断时处理安装异常。自动选择检查/计划，执行前简洁确认问题、下载和影响；重装等进入高级，不默认整包重装。

- 实际启动仍核验当前发布、占用、事务、源码/环境并等待真实服务；同一次操作内可消除已证明重复验证，不引入跨次信任缓存。
- 只读检查和计划允许网页运行；目标引擎训练/占用/变更时拒绝该目标修改，无冲突引擎仍可维护。中英同步，旧版本精准维护边界不变。
