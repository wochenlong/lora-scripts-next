# 目标1：安装清单（manifest）

回答的问题：当显示版本号相同，启动器如何可靠区分和验证两条真实发布？

范围：schema 1嵌入清单、完整commit/id、HTTPS归档及SHA256/体积、Python/uv身份、environment_recipe、profile schema/data_contract、required_files、receipt。远程签名目录、自更新与完整wheel锁不在本轮。

前置：已读真实catalog与两份归档元数据；main/dev均为3.3.1-dev。后继：字段/拒绝规则冻结才允许G2依据其创建目录。

## 验收标准

1. id使用安全单段路径且绑定完整commit；不按VERSION合并发布，不把main改称稳定。
2. 不允许UI注入URL/命令/任意文件路径；未知schema/非法id/错误hash/超限归档拒绝，原current和profile不变。
3. 归档经校验、staging展开、入口检查后登记；receipt写明发布事实。receipt只能帮助发现，不能替代实际源码和环境检查。
4. 失败保留日志/staging；registry缺失可从真实receipt发现已安装项，但不能猜current。
