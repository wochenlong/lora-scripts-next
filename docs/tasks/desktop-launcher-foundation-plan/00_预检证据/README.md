# 预检与证据入口

事实基线见 [preflight-source-review.md](preflight-source-review.md)；规划门禁见 [gate-validation-checklist.md](gate-validation-checklist.md)；全部治理模板合并到 [governance.md](governance.md)。

`governance.md` 按测试证据、失败报告、阶段完成门、清理报告、风险授权、变更控制、可行性报告分节，保留各模板职责。

本目录存规则与精简结论。原始 stdout/stderr、JSON、截图、哈希、联接/进程快照写到 `E:/OpenSourceTeamWork/workspace/tools/launcher-foundation-20261028/stageN/<case>/`，避免把运行环境或个人资料放进仓库。

每次执行记录实际 EXE SHA256、catalog commit、命令参数、开始/结束、退出码和预算；失败结果也保留。运行证据不是本计划的第二份进度文档。
