# 自然语言打标使用与维护

当前功能在 `feat/NL-Captioning` 分支开发，完整矩阵和从零重建尚未验收完成。最终交付状态以任务书为准。

在“数据集 → 模型打标”选择 Tag 标签、自然语言或组合打标。Tag 继续使用 WD/CL；组合模式保留真实 Tag 和自然语言描述两个部分。自然语言不会参与 Tag 的逗号拆分、排序、去重或下划线转换。

## 共用 LLM 配置

打标页“管理视觉 Profile”与标签编辑翻译设置使用同一配置。远程始终优先；本地兜底开关默认关闭，只有显式开启且远程失败时才调用本地。打标要求接口声明 vision 并支持所选语言，翻译只要求 text。给纯文本接口勾选视觉能力并不能使模型获得视觉能力，应先执行连接测试。

远程图片请求仅含受限 JPEG data URL 和提示词，不携带本地图片路径或数据集名称。真实 Key 由可信后端管理通道注入，后端配置和读取响应只保留掩码，重启后需重新注入。不要把 Key 写入脚本、环境文件、日志、仓库或截图。验收工具支持后端终端隐藏输入。

本地中文候选为 Qwen3-VL-2B Q4_K_M + Q8 mmproj，模型和视觉投影合计约 1.55 GB，CPU 实测模型进程峰值约 3.1 GB，实际整机需求还包括应用与系统。三图描述实测约 14 秒；组合模式含 ONNX 约 24 秒。首次安装还需要 llama.cpp 运行时，资产由翻译与打标共用。SmolVLM 仅作为英文低资源候选，不宣称中文质量。

## 提示词、预览与任务

选择语言并编辑提示词；模板支持页面提示的变量，语言须与严格 JSON 中的 language 一致。模型只返回 caption 和 language，非法 JSON、错误语言、超长或截断输出会报错。可保存预设，撤销未保存修改；任务启动后冻结提示词，修改或删除预设不会改变已有任务和失败重试的提示词。

“测试当前图片”用于预览，不写 caption。确认后启动批量任务，查看进度、成功/跳过/失败/取消数和逐项错误。取消保留已完成的写回，不提交正在生成的描述；失败重试只处理失败项。后端重启后不会自动恢复推理或写盘，可从历史报告显式重试。

写回使用任务开始时的文件哈希，用户或外部程序改动会触发 caption_conflict，并保留新内容。训练使用中的数据集受到占用保护。自然语言的前置/追加用空行分隔，Tag 兼容旧排序和去重规则。

## 编辑、回滚与保留

标签编辑器按记录的 tag/natural/mixed 来源展示，mixed 只将真实 Tag 部分映射为 Tag。外部改动使既有自然语言来源失效时按 unknown 保护原文。无来源的旧短文本存在歧义，编辑前需要确认内容。保存、批量操作、撤销和重做均有文件哈希检查；冲突后刷新数据再处理。

任务历史可回滚该任务仍拥有且内容未改变的输出。回滚恢复原始字节与来源，只删除该任务新建且未被修改的 caption；冲突项保持原样并返回计数。另一任务或编辑器后来保存了相同文本，也会阻止较早任务回滚它。

清除历史会删除选定任务、该任务备份和回滚记录，保留当前 caption 与格式来源；清除后失去该任务的回滚能力。任务备份不会自动按时间过期，维护时先检查报告与回滚需求，再逐项清除。缓存与备份属于后端私有 SQLite，可能保存处理后的描述和原始 caption；不要上传数据库或把它加入 Git。关闭缓存会绕过读取与新增缓存，不代表删除已存内容。

空配置、无词库或模型时页面可启动，生成入口会提示配置视觉接口或安装可选本地模型。CPU torch 环境可能显示训练 GPU 不可用提示，该提示不阻止远程或 CPU 打标。
