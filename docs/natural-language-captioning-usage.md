# 自然语言打标使用与维护

本文描述自然语言打标及共享 LLM 的使用方式。可复现的回归命令、Python 版本和本轮验证边界见 [验证说明](caption-validation.md)。历史沙盒和人工评分属于本地验收证据，不等同于仓库 CI 结果。

在“数据集 → 模型打标”先选择本地模型或已配置的 API 服务，再选择具体模型。WD/CL 输出原生 Tag；视觉模型输出自然语言 Caption，参数和提示词随模型能力显示。当前不提供混合标注。自然语言不会参与 Tag 的逗号拆分、排序、去重或下划线转换，中文标签释义只用于阅读。

## 共用 LLM 配置

打标页“LLM模型管理”、设置页和标签编辑翻译设置使用同一配置。远程始终优先，本地兜底与两类缓存缺省开启，可在“高级设置”中关闭；已保存的关闭值会保留。模型卡默认折叠，只显示名称与启用开关，展开后编辑接口配置。连接测试自动检测文本和视觉能力，只有实际通过的能力才可使用；文本接口可翻译，视觉未通过的接口不能打标。翻译使用内部固定系统提示词，界面不提供修改入口。

远程图片请求仅含受限 JPEG data URL 和提示词，不携带本地图片路径或数据集名称。真实 Key 由可信后端管理通道注入，后端配置和读取响应只保留掩码，重启后需重新注入。不要把 Key 写入脚本、环境文件、日志、仓库或截图。验收工具支持后端终端隐藏输入。

当前统一本地模型为 Qwen3.5-2B Q4_K_M + 同版本 F16 mmproj，模型和投影合计约 1.82 GiB，配套 llama.cpp b11327 运行时。安装、服务状态、大小、预计内存与启停按钮集中在 LLM 模型管理的本地模型卡中；翻译与打标共用同一份资产和服务。整机内存需求还包括应用与系统。

## 提示词、预览与任务

Tag 与自然语言打标默认递归搜索子目录，界面不再提供递归开关。模型选择行右侧随打标方式切换：Tag 显示“预下载 Tag 模型”（已下载时禁用），自然语言 Caption 显示“LLM模型管理”；预下载入口只准备所选 WD/CL 的 ONNX 和标签文件，不下载 LLM。

自然语言模型参数默认最大生成 token 为 1024、采样温度为 0.7、并发请求数为 3。并发可设为 1–16 的整数，用于同一批任务内的远程请求，不代表同时运行多个打标任务；生成完成后仍逐个原子写回。使用本地模型或远程失败后本地兜底时，会排队并保持一次一个实际推理请求，避免重复加载模型和增加内存压力。取消会终止在途请求并停止派发剩余图片；失败重试保留原任务的并发设置。单图预览始终只有一个请求。预览图片路径位于“启动打标”按钮下方；本地服务管理集中在 LLM 模型管理。

自然语言输出语言独立于界面语言。选择提示词预设并编辑打标提示词和可选打标系统提示词；模板支持页面提示的变量，语言须与严格 JSON 中的 language 一致。模型只返回 caption 和 language，非法 JSON、错误语言、超长或截断输出会报错。内置模板修改后另存为用户预设，可保存、另存为、恢复默认或撤销草稿；切换前会提示未保存修改。用户预设位于 user_data/presets/，kind=caption_prompt，与训练预设隔离；默认引用保存在 settings.json。旧预设可经明确确认一次性导入，刷新预设保留当前草稿。任务启动后冻结提示词和参数，修改或删除预设不会改变已有任务和失败重试的提示词。

Tag 和自然语言的“测试当前图片”均复用批量生成配置，不写 caption。确认后启动批量任务，底部查看进度、成功/跳过/失败/取消数和逐项错误；也可进入任务页查看状态、日志和报告。取消保留已完成的写回，不提交正在生成的描述；原生 Tag 推理会等待当前模型调用结束并卸载后释放占用。失败重试只处理失败项并使用原任务提示词与参数。刷新页面可读取服务端状态；后端重启后不会自动推理或写盘，未完成任务可显式重试。新任务在 user_data/tasks/dataset-tagger/ 按日期与 UUID 归档 config.json、task.json、日志，档案写入失败不启动推理。

已有标注默认跳过，覆盖需要明确选择；自然语言仅提供跳过和覆盖。写回使用任务开始时的文件哈希，用户或外部程序改动会触发 caption_conflict，并保留新内容。训练使用中的数据集受到占用保护。Tag 保留旧输出与追加选项的兼容。

## 编辑、回滚与保留

标签编辑器按记录的 tag/natural/mixed 来源展示，mixed 只将真实 Tag 部分映射为 Tag。外部改动使既有自然语言来源失效时按 unknown 保护原文。无来源的旧短文本存在歧义，编辑前需要确认内容。保存、批量操作、撤销和重做均有文件哈希检查；冲突后刷新数据再处理。

任务历史可回滚该任务仍拥有且内容未改变的输出。回滚恢复原始字节与来源，只删除该任务新建且未被修改的 caption；冲突项保持原样并返回计数。另一任务或编辑器后来保存了相同文本，也会阻止较早任务回滚它。

清除历史会删除选定任务、该任务备份和回滚记录，保留当前 caption 与格式来源；清除后失去该任务的回滚能力。任务备份不会自动按时间过期，维护时先检查报告与回滚需求，再逐项清除。缓存与备份属于后端私有 SQLite，可能保存处理后的描述和原始 caption；不要上传数据库或把它加入 Git。关闭缓存会绕过读取与新增缓存，不代表删除已存内容。

在任务页删除记录只隐藏任务投影，保留数据集和档案；从打标页清除历史则同时清除 SQLite 历史/备份并隐藏任务投影，但仍保留图片与当前标注。被删除的任务页记录在服务重启后不会重新出现。档案目录目前保留以供审计，可能包含私有数据集路径和提示词，请勿公开整个 user_data。

空配置、无词库或模型时页面可启动，生成入口会提示配置视觉接口或安装可选本地模型。CPU torch 环境可能显示训练 GPU 不可用提示，该提示不阻止远程或 CPU 打标。


自然语言默认以英文打标为主；提示词预设统一控制语言与描述方式，切换预设时同时应用完整提示词、系统提示词和语言，用户自定义模板保留，英文请求出现中文正文会失败而不写盘。英文预设下自定义中文提示词会显示建议，可用“恢复默认模板”切到英文内置版。

标签编辑页会直接展开自然语言原文，重新进入或加载会读取磁盘；真正的未保存草稿继续保留，必要时点“恢复磁盘原文”并确认。打开“中文译文（自然语言）”可查看整句译文，使用共享LLM的文本能力；远程优先，本地兜底遵循共用高级设置且要求模型服务已启动。中文为主的文本直接显示，不调用模型；英文夹带少量中文标牌仍翻译。译文只读，不保存回原标注；切换图片/关闭/修改原文会取消上一请求。自然语言继续禁用Tag清理、排序、拖拽和批量Tag操作。

单图编辑侧栏的中文译文开关旁提供“翻译设置”。Tag 和自然语言均可通过该设置内的“LLM模型管理”直接打开共用管理组件，无需离开编辑页；关闭模型管理会返回翻译设置，当前标注草稿保留。保存配置或改变本地运行状态后，编辑器重新读取共用配置与服务状态；取消模型管理会丢弃其中未保存的配置编辑。
# 2026-10-10 手测增量说明

自然语言默认英文。预设提供简短（1–2句）与详细（3–5句）的完整内置提示词；没有独立输出语言或详略下拉框；句数是模型生成要求，不会自动裁剪结果。英文选择的 user/system prompt 均为英文；中文同理。自定义提示词的详略由内容决定，切换预设时先确认未保存修改。页面显示只读预设语言和纯文本 .txt 落盘格式；自定义继承当前预设语言，要改变语言先选择对应预设再编辑/另存。模型不支持预设语言时会阻止生成，不会静默修改模板。

已保存的用户默认预设不会被新模板覆盖。如果想体验新版模板，请先选择内置预设或点击“恢复默认模板”。省略 prompt 的后端请求会按目标语言选择完整默认模板；自定义与用户预设优先。

重点手测：英文实际正文、中文模板切换、简短与详细差异、预览不写TXT、Editor显示实际原文、英文整句中文译文、中文原文免模型翻译、译文不改训练文本、自然语言不提供Tag清理/排序/拖拽及批量Tag操作。
