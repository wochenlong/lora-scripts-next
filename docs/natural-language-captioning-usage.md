# 自然语言打标使用与维护

当前功能已在 `feat/NL-Captioning` 完成 Issue #409 对齐开发、完整功能矩阵、真实本地/ONNX/浏览器、人工评分、正式Zero-Short和全新隔离重建；2026-10-09清理完成门已关闭。Windows四项原生symlink权限失败使用用户批准的独立Linux原case组合验收；fresh远程未配置，如实记录。详见任务书与最终验收审计。

在“数据集 → 模型打标”先选择本地模型或已配置的 API 服务，再选择具体模型。WD/CL 输出原生 Tag；视觉模型输出自然语言 Caption，参数和提示词随模型能力显示。当前不提供混合标注。自然语言不会参与 Tag 的逗号拆分、排序、去重或下划线转换，中文标签释义只用于阅读。

## 共用 LLM 配置

打标页“管理视觉 Profile”与标签编辑翻译设置使用同一配置。远程始终优先；本地兜底开关默认关闭，只有显式开启且远程失败时才调用本地。打标要求接口声明 vision 并支持所选语言，翻译只要求 text。给纯文本接口勾选视觉能力并不能使模型获得视觉能力，应先执行连接测试。

远程图片请求仅含受限 JPEG data URL 和提示词，不携带本地图片路径或数据集名称。真实 Key 由可信后端管理通道注入，后端配置和读取响应只保留掩码，重启后需重新注入。不要把 Key 写入脚本、环境文件、日志、仓库或截图。验收工具支持后端终端隐藏输入。

本地中文候选为 Qwen3-VL-2B Q4_K_M + Q8 mmproj，模型和视觉投影合计约 1.55 GB，已有探针中 CPU 模型进程峰值约 3.1 GB，实际整机需求还包括应用与系统。探针三图描述约 14 秒，当前契约的最终真实验收以任务书为准。首次安装还需要 llama.cpp 运行时，资产由翻译与打标共用。SmolVLM 仅作为英文低资源候选，不宣称中文质量。

## 提示词、预览与任务

自然语言输出语言独立于界面语言。选择语言并编辑提示词和可选系统提示词；模板支持页面提示的变量，语言须与严格 JSON 中的 language 一致。模型只返回 caption 和 language，非法 JSON、错误语言、超长或截断输出会报错。内置模板修改后另存为用户预设，可保存、另存为、恢复默认或撤销草稿；切换前会提示未保存修改。用户预设位于 user_data/presets/，kind=caption_prompt，与训练预设隔离；默认引用保存在 settings.json。旧预设可经明确确认一次性导入，刷新预设保留当前草稿。任务启动后冻结提示词和参数，修改或删除预设不会改变已有任务和失败重试的提示词。

Tag 和自然语言的“测试当前图片”均复用批量生成配置，不写 caption。确认后启动批量任务，底部查看进度、成功/跳过/失败/取消数和逐项错误；也可进入任务页查看状态、日志和报告。取消保留已完成的写回，不提交正在生成的描述；原生 Tag 推理会等待当前模型调用结束并卸载后释放占用。失败重试只处理失败项并使用原任务提示词与参数。刷新页面可读取服务端状态；后端重启后不会自动推理或写盘，未完成任务可显式重试。新任务在 user_data/tasks/dataset-tagger/ 按日期与 UUID 归档 config.json、task.json、日志，档案写入失败不启动推理。

已有标注默认跳过，覆盖需要明确选择；自然语言仅提供跳过和覆盖。写回使用任务开始时的文件哈希，用户或外部程序改动会触发 caption_conflict，并保留新内容。训练使用中的数据集受到占用保护。Tag 保留旧输出与追加选项的兼容。

## 编辑、回滚与保留

标签编辑器按记录的 tag/natural/mixed 来源展示，mixed 只将真实 Tag 部分映射为 Tag。外部改动使既有自然语言来源失效时按 unknown 保护原文。无来源的旧短文本存在歧义，编辑前需要确认内容。保存、批量操作、撤销和重做均有文件哈希检查；冲突后刷新数据再处理。

任务历史可回滚该任务仍拥有且内容未改变的输出。回滚恢复原始字节与来源，只删除该任务新建且未被修改的 caption；冲突项保持原样并返回计数。另一任务或编辑器后来保存了相同文本，也会阻止较早任务回滚它。

清除历史会删除选定任务、该任务备份和回滚记录，保留当前 caption 与格式来源；清除后失去该任务的回滚能力。任务备份不会自动按时间过期，维护时先检查报告与回滚需求，再逐项清除。缓存与备份属于后端私有 SQLite，可能保存处理后的描述和原始 caption；不要上传数据库或把它加入 Git。关闭缓存会绕过读取与新增缓存，不代表删除已存内容。

在任务页删除记录只隐藏任务投影，保留数据集和档案；从打标页清除历史则同时清除 SQLite 历史/备份并隐藏任务投影，但仍保留图片与当前标注。被删除的任务页记录在服务重启后不会重新出现。档案目录目前保留以供审计，可能包含私有数据集路径和提示词，请勿公开整个 user_data。

空配置、无词库或模型时页面可启动，生成入口会提示配置视觉接口或安装可选本地模型。CPU torch 环境可能显示训练 GPU 不可用提示，该提示不阻止远程或 CPU 打标。


自然语言默认以英文打标为主；未修改的内置提示词和系统提示词随输出语言切换，用户自定义模板保留，英文请求出现中文正文会失败而不写盘。英文选择下自定义中文提示词会显示建议，可用“恢复默认模板”切到英文内置版。

标签编辑页会直接展开自然语言原文，重新进入或加载会读取磁盘；真正的未保存草稿继续保留，必要时点“恢复磁盘原文”并确认。打开“中文译文（自然语言）”可查看整句译文，使用共享LLM的文本能力；远程优先，本地需要勾选兜底并已启动。中文为主的文本直接显示，不调用模型；英文夹带少量中文标牌仍翻译。译文只读，不保存回原标注；切换图片/关闭/修改原文会取消上一请求。自然语言继续禁用Tag清理、排序、拖拽和批量Tag操作。
